# homebrew-tap

Homebrew tap for pkc918 apps.

## Usage

```bash
brew tap pkc918/tap
```

## Apps

| App | Description | Version | Source | Install |
| --- | --- | --- | --- | --- |
| DevPilot | macOS port monitoring tool | macOS 15+ | [pkc918/DevPilot](https://github.com/pkc918/DevPilot) | `brew install --cask devpilot` |
| mpc-plus | CLI for uploading mini-program builds (WeChat, Douyin, Alipay, XHS) |  | [pkc918/mpc-plus](https://github.com/pkc918/mpc-plus) | `brew install mpc-plus` |
